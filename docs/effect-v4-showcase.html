Change logThe cutover

Effect at the boundaries.

The refactor uses Effect v4 services and scoped resources, makes cassette operations composable Effects, and brings both WebSocket interfaces onto a shared transcript.

Before After
Synchronous cassette existence and removal helpers. Effect-based hasCassette and removeCassette.
Socket replay responsibilities across interface implementations. A shared transcript, with separate Effect Socket and native-constructor adapters.
A scheduling yield treated as enough time to deliver a server burst. A distinct delivery-ready Deferred acknowledges the next client event or end only after dispatch.

Public surface: named root type exports and a CassetteService namespace. Storage and configuration use FileSystem, Path, and ConfigProvider; resource lifetimes are scoped. HTTP cancellation preserves recording order.

Replay trackDelivery order

Yielding is not acknowledgment.

A long server burst may outlast one scheduler yield. Replay needs an explicit delivery boundary before it acknowledges the next client event—or the end of the transcript.

EXPLANATORY MODEL · NOT A LIVE RUNTIMEStep 1 of 5

Client A starts this exchange.

The transcript accepts the first client event. The following server burst must be dispatched before the next client event or end is acknowledged.

Illustrative burst: four frames · not dispatched

The distinction: the delivery-ready signal acknowledges dispatch, not wire timing, backpressure, or completion of arbitrary application work. The four-frame display is illustrative; the regression exercises a 10,000-frame burst.

Time trackClock anchoring

Rewind the clock, too.

A recording session keeps its original recordedAt timestamp as interactions are appended. Tests can anchor Effect’s TestClock to that instant instead of drifting with the date of replay.

Effect test-body excerpt · local server and directory supplied by the test fixture 

import { DateTime, Duration, Effect, Exit } from "effect"
import { TestClock } from "effect/testing"
import { HttpClient, HttpClientRequest } from "effect/unstable/http"
import { HttpRecorder, setTestClockToRecordedAt } from "effect-http-recorder"

const requestItems = Effect.gen(function* () {
  const now = yield* DateTime.now
  const query = new URLSearchParams({
    from: DateTime.formatIso(DateTime.subtract(now, { days: 7 })),
    to: DateTime.formatIso(DateTime.add(now, { days: 7 })),
  })
  const http = yield* HttpClient.HttpClient
  const response = yield* http.execute(
    HttpClientRequest.get(`${server.url}/items?${query}`),
  )
  return yield* response.text
}).pipe(Effect.provide(HttpRecorder.layerFetch("items", {
  directory: directory.path,
})))

const scenario = Effect.gen(function* () {
  yield* TestClock.setTime(Date.parse("2026-09-10T15:50:00Z"))
  const original = yield* requestItems
  yield* server.stop

  yield* TestClock.adjust(Duration.days(30))
  const drifted = yield* Effect.exit(requestItems)

  yield* setTestClockToRecordedAt("items", {
    directory: directory.path,
  })
  const replay = yield* requestItems
  return {
    driftedReplayFailed: Exit.isFailure(drifted),
    anchoredReplayMatches: replay === original,
  }
})

recordedAt("items") reads the recorded instant without moving the clock. readCassette("items") reads the full cassette. The clock helper performs the explicit rewind.

Timestamp present
The clock helper sets TestClock to the recorded instant.
Cassette absent
The clock helper uses live time, allowing a new recording run. Direct recordedAt and readCassette reads still report the missing cassette.
Legacy timestamp absent
MissingRecordedAtError is distinct from invalid data. Re-record to enable clock anchoring.
Timestamp malformed
InvalidCassetteError surfaces the invalid cassette rather than silently substituting live time.

    The regression fails before the delivery acknowledgment fix and passes after it. Greeting and queued-close smoke checks also pass.

What this does not promise

  • Responses are buffered. This is not a claim of streaming-response fidelity.
  • Replay preserves the conversation, not the network. Wire timing and backpressure fidelity are outside the guarantee.
  • Effect v4 remains a pinned release candidate. The target is rc112, not a claim of compatibility with every future v4 release.
